### ✅ Available projects

- [Scrabble solveur 🎲](https://scrabble-solveur.vercel.app) : This project aims to find all valid words a player can form on a Scrabble board using their available letters :
  - Finds all valid words a player can form on a Scrabble board using available letters.
  - Follows Scrabble rules, ensuring correct placement and interaction with existing words.
  - Calculates scores, including letter and word bonuses.
  - Accounts for points from parallel words formed during placement.
  - Optimizes gameplay by identifying high-scoring moves.
